# Cloud Voice（云端歌声合成）

Cloud Voice 把 TuneLab 里的音符发送到**云端 HTTP(S) 歌声合成服务**，取回音频；未配置服务时可用
内置的离线演示引擎先跑通整条链路。

## 它做什么

- 读取 part 的音符（歌词、音高、钉死音素）、音高轨与音高偏差轨、`dynamics` / `breathiness` 自动化轨。
- 把这些音乐信息采样成一份 JSON 请求（协议 `tunelab-cloudvoice` v1），POST 到你配置的端点。
- 加载时自动向服务商 `GET <服务地址同级的 /voices>` 拉取声库目录——只需要服务地址与 API Key，
  不需要手工粘贴声库列表。
- 读取后端能力 schema（`/voices.schema` 或 `GET <服务地址同级的 /schema>`）：属性面板参数、
  可画线自动化轨、只读回显轨、自动音高支持都由服务端决定。
- 解码返回的音频（base64 PCM / WAV 或下载 URL），并回填合成音素、音高回显与 energy 参数回显。
- 按音符间隙分块、逐块合成；编辑后只重合成受影响的块。

## 快速开始

1. 打开 **设置 → 扩展 → Cloud Voice**。
2. 填 **Service URL**（即 `.../synthesize` 端点）与 **API Key** 即可：插件加载时会自动从
   `GET .../voices` 拉取服务商的声库目录，无需手工粘贴。服务地址留空则使用内置离线演示声库。
3. 新建**声源片段**，在声源选择器里挑服务商的声库。
4. 输入歌词（每个音符一个汉字或 `la` 这样的拉丁音节），播放或编辑即可看到后台逐块合成与状态带。

## 说明

- 引擎 id `CloudVoice` 会写进工程文件。设置按扩展持久化、跨工程共享；API Key 由宿主存进系统钥匙串，
  不会进工程文件。
- 歌词 `-` 是**延音**：延长前一个音符的元音（melisma），不另起音节，与编辑器约定一致。
- 后端声明 `pitch.auto` 时，插件会请求自动音高，并把后端实际渲染出的 F0 显示为合成音高。
- 云端报错时该块变红、状态带里显示服务端消息；改一下该块（或修好设置）即可重试。
